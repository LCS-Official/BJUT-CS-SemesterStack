# BJUT-CS-SemesterStack：计科实本科资料归档

> 按“学期 → 课程”两级结构整理的个人学习资料归档。

本目录记录本科阶段部分课程的复习资料、实验与课程设计。课程内容、任课教师和考核方式可能随学年调整，README 中的经验仅代表当时情况。

## 收录内容

- 个人整理的复习笔记、课程总结与学习资料；
- 作业、实验报告与课程设计文档；
- 可公开的源代码、工程源文件和必要的小型数据；
- 已确认允许再分发的试题与参考资料。

## 默认不公开

- 教师课件、教材扫描件及来源或授权不明确的资料；
- 真实账号口令、API 密钥、云服务器地址等敏感配置；
- 安装包、可执行文件、编译缓存、IDE 缓存及可重复生成的工程产物；
- 大型原始数据、模型、演示视频和重复压缩包。

## 使用说明

1. 先进入对应学期，再选择课程目录。
2. 各课程 README 中的复习建议具有时效性，请以当学期教学要求为准。
3. 资料仅供学习和交流，请勿将他人的报告或代码直接作为自己的作业提交。
4. 若公开内容涉及版权或隐私问题，可通过仓库 Issue 联系维护者处理。
