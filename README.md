# BJUT-CS-SemesterStack：计科实本科资料归档


> 按“学期 → 课程”两级结构整理的个人学习资料归档。

## 收录内容


- 个人整理的复习笔记、课程总结与学习资料；

- 作业、实验报告与课程设计文档；
- 可公开的源代码、工程源文件和必要的小型数据；

- 已确认允许再分发的试题与参考资料。



## 使用说明



1. 先进入对应学期，再选择课程目录。

2. 资料仅供学习和交流，请勿将他人的报告或代码直接作为自己的作业提交。

3. 若公开内容涉及版权或隐私问题，可通过仓库 Issue 联系维护者处理。
