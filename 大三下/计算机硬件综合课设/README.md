# 计算机硬件综合课设

> 所属学期：大三下

## 项目概览

本目录主要保存基于 PYNQ-Z1 的疲劳检测系统，包括 Vivado/HLS 工程、嵌入式与上位机代码、设计报告、答辩材料和演示素材。

## 目录说明

- `01_Vivado工程（包括顶层工程、顶层依赖的vivado工程、HLS导出给vivado的工程）/`：顶层与依赖工程的可复现源文件；
- `HLS工程/`：算法实现、测试和 HLS 工程源文件；
- 其余目录：嵌入式/上位机代码、设计文档、报告与答辩材料。

Vivado/HLS 生成目录、构建缓存、演示视频和外部大型模型不纳入仓库。模型来源与下载方式见 `HLS工程/eyeblink8/README.md`。
