## 5. 与 B 模块的接入建议

B 模块目前文档中需要 A 提供：

```text
CURRENT_ACTOR()
CAN_MANAGE_LAB(user_id, lab_id)
```

A 当前可提供对应包装：

```python
def CURRENT_ACTOR():
    return platform_store.actor_from_session(session) or {}

def CAN_MANAGE_LAB(user_id, lab_id):
    actor = platform_store.actor_from_session(session)
    role = actor["role"] if actor else None
    return platform_store.can_manage_lab(user_id, lab_id, role)
```

建议后续由统一主应用完成包装和注入，不建议直接在 B 模块内部复制 A 的权限逻辑。
