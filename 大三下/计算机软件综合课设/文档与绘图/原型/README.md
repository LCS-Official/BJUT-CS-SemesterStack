# 智能实验室预约与设备管理系统 - 轻量前端原型

## 打开方式

推荐双击打开：

```text
启动动态原型.bat
```

然后在浏览器访问：

```text
http://127.0.0.1:5050/
```

如果批处理无法启动，也可以在本目录执行：

```powershell
conda run -n csv python app.py
```

`index.html` 也可以直接双击打开，但那只是静态查看；动态按钮功能需要通过 `app.py` 启动 Flask 后端。

## 原型定位

用于第二次检查展示“主要页面与业务流程”。当前版本参考《教师检查演示与完整测试流程_2026-07-12.md》整理为轻量动态原型：连接本地 Flask 后端，按钮会调用 `/api/...` 接口并改变后端内存状态；不连接真实数据库。

覆盖页面：

1. 流程总览
2. 学生端：资源查询与预约
3. 学生端：我的预约 / 签到签退
4. 学生端：设备报修
5. 学生端：信用中心
6. 实验室管理员端：预约审批
7. 实验室管理员端：设备与报修处理
8. 实验室管理员端：违规处理 / 统计
9. 系统管理员端：用户权限 / 参数 / 日志

## 建议演示顺序

1. 打开“流程总览”，说明 A/B/C/D 模块分工。
2. 进入“资源查询与预约”，选择设备并提交预约。
3. 进入“预约审批”，点击“通过”。
4. 回到“我的预约 / 签到签退”，点击“签到”，再点击“签退”。
5. 展示“设备报修”“信用中心”“系统参数和日志”等入口。
6. 可点击“重置演示数据”恢复初始状态，重复演示。

## 口径

可以这样解释：

> 这个原型用于展示页面结构和主业务流程。当前 B 预约模块已有后端代码和测试；原型中的预约提交、审批、签到签退等按钮会请求本地 Flask 接口并改变后端状态，后续可替换为统一 Flask 主入口和真实数据库接口。
