# 实验三报告：语法制导的三地址代码生成子系统

## 一、实验目的

掌握计算机语言语法分析程序设计与属性文法应用的实现方法，在词法分析、语法分析的基础上，为实验指导书中的微型语言生成等效三地址代码。

## 二、系统功能概述

本子系统完成从源程序到三地址代码的翻译，支持如下语言成分：

- 标识符：`letter(letter|digit)*`
- 整数常量：十进制、八进制、十六进制，并统一转换为十进制属性值
- 算术表达式：`+ - * /`，满足乘除优先于加减，同级左结合
- 条件表达式：`> < = >= <= <>`
- 语句：赋值语句、`if then`、`if then else`、`while do`、复合语句 `{ P }`

输出结果为三地址代码，临时变量形如 `t1, t2, ...`，标号形如 `L0, L1, ...`。

## 三、文法与语法制导定义

采用实验指导书给出的核心文法：

```text
P -> L | L P
L -> S ;
S -> id = E
S -> if C then S
S -> if C then S else S
S -> while C do S
S -> { P }
C -> E > E | E < E | E = E | E >= E | E <= E | E <> E
E -> E + T | E - T | T
T -> T * F | T / F | F
F -> ( E ) | id | int8 | int10 | int16
```

主要属性设计：

- `E.place/T.place/F.place`：表达式结果所在位置，可以是标识符、常量或临时变量。
- `C.true/C.false`：条件为真/假时跳转到的标号。
- `S.next`：语句执行结束后应跳转或顺序到达的位置。
- `code`：语句或表达式对应的三地址代码序列。

核心语义规则：

```text
id = E:
    E.code
    id := E.place

E1 + T:
    E.place = newtemp()
    E.code = E1.code || T.code || gen(E.place := E1.place + T.place)

T1 * F:
    T.place = newtemp()
    T.code = T1.code || F.code || gen(T.place := T1.place * F.place)

C: E1 relop E2
    E1.code || E2.code
    if E1.place relop E2.place goto C.true
    goto C.false

while C do S1:
    begin = newlabel()
    C.true = newlabel()
    C.false = S.next
    S1.next = begin
    begin:
    C.code
    C.true:
    S1.code
    goto begin
```

## 四、主要数据结构

程序位于 `task3_codegen.py`，主要结构如下：

- `Token`：词法单元，保存种别、原始文本、属性值、行列号。
- `Lexer`：词法分析器，逐字符扫描源程序，生成 token 序列。
- `Parser`：递归下降语法分析器，生成抽象语法树。
- `Program/Assign/If/While/Block`：语句类节点。
- `Var/Const/BinOp/Condition`：表达式与条件类节点。
- `CodeGenerator`：三地址代码生成器，维护临时变量计数器、标号计数器和输出代码序列。

## 五、算法基本思想

1. 词法分析阶段从输入文件读取源程序，识别关键字、标识符、整数、运算符和分隔符。
2. 语法分析阶段按 `P/L/S/C/E/T/F` 结构递归下降，其中表达式拆分为 `expr/term/factor`，自然保证四则运算优先级。
3. 代码生成阶段对表达式采用综合属性 `place`。当遇到二元运算时，递归生成左右操作数代码，再申请新临时变量保存结果。
4. 条件语句和循环语句采用继承属性标号。条件表达式生成两条跳转代码，分别跳向真出口和假出口。
5. 语句序列之间生成后继标号，使控制流可以从循环或分支跳转到下一条语句。

## 六、测试数据与结果

### 测试输入

```text
while (a3+15)>0xa do if x2 = 07 then while y<z do y = x * y / z; c=b*c+d;
```

### 程序输出

```text
L1:
    t1 := a3 + 15
    if t1 > 10 goto L2
    goto L0
L2:
    if x2 = 7 goto L3
    goto L1
L3:
    if y < z goto L4
    goto L1
L4:
    t2 := x * y
    t3 := t2 / z
    y := t3
    goto L3
    goto L1
L0:
    t4 := b * c
    t5 := t4 + d
    c := t5
```

输出与指导书参考结果等效，体现了循环入口、条件真假出口、临时变量和顺序语句后继标号的生成过程。

## 七、运行方法

在 `task3` 目录执行：

```bat
python task3_codegen.py input.txt output.txt
```

或直接执行：

```bat
run.bat
```

## 八、实验体会

三地址代码生成的关键不只是“打印代码”，而是要在语法结构中正确维护属性。表达式的 `place` 决定临时变量如何传递，条件语句的真假出口和语句的 `next` 决定控制流是否正确。通过把词法分析、语法分析和代码生成拆分为独立模块，系统结构更加清晰，也便于后续扩展符号表、类型检查或目标代码生成。
