# 实验三：语法制导的三地址代码生成器

## 功能

本程序实现实验指导书中的微型语言翻译系统，可以识别：

- 标识符、十进制整数、八进制整数、十六进制整数；
- `+ - * /` 四则运算，保持优先级和左结合；
- `> < = >= <= <>` 条件表达式；
- 赋值语句、`if then`、`if then else`、`while do`、`{ ... }` 复合语句。

输出为等效三地址代码，自动生成临时变量 `t1, t2, ...` 和标号 `L0, L1, ...`。

## 运行方法

在 `task3` 目录运行：

```bat
python task3_codegen.py input.txt output.txt
```

也可以直接双击或执行：

```bat
run.bat
```

## 典型测试

指导书示例输入：

```text
while (a3+15)>0xa do if x2 = 07 then while y<z do y = x * y / z; c=b*c+d;
```

程序会生成等效的三地址代码序列，十六进制 `0xa` 转换为 `10`，八进制 `07` 转换为 `7`。

## 设计要点

- 词法分析：逐字符扫描，返回 token 序列及整数的十进制属性值。
- 语法分析：使用递归下降方法，结构与实验文法 `P/L/S/C/E/T/F` 对应。
- 代码生成：表达式使用综合属性 `place`，条件和语句使用继承属性 `true/false/next`，按语法制导定义生成跳转和赋值代码。
