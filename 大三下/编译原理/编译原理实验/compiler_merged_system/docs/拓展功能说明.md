# 拓展功能说明

本版本在原合并系统基础上保留了 `parse.txt` 两栏解释和 `parse_tree.txt` 缩进语法树，同时补充了指导书中的若干附加要求。

## 实验一：词法分析拓展

- 支持从文件读取源程序，并用 `scan()` 每次返回一个 Token。
- 支持保留字：`if / then / else / while / do`。
- 支持三类整数：`INT10 / INT8 / INT16`。
- 支持三类实数：`REAL10 / REAL8 / REAL16`。
  - 例：`6.2 -> REAL10 6.2`
  - 例：`07.4 -> REAL8 7.5`
  - 例：`0X88.80 -> REAL16 136.5`
- 支持拓展标识符：`my_var`、`obj.field` 这类形式。
- 维护标识符表 `symbols.txt` 和常量表 `constants.txt`。
- 记录行号、列号；非法字符写入 `errors.txt`。

## 实验二：语法分析拓展

- 支持多行、多语句输入。
- 支持赋值、`if`、`if-else`、`while`、复合语句 `{ P }`。
- 输出详细产生式解释 `parse.txt`。
- 输出缩进语法树 `parse_tree.txt`，方便展示程序结构。
- 出错时输出错误位置，并尽量同步到 `;`、`}` 或 EOF 后继续分析。

## 实验三：三地址代码拓展

- 在递归下降分析过程中同步生成三地址代码。
- 支持 `newtemp()` 生成 `t1/t2/...`。
- 支持 `newlabel()` 生成 `L0/L1/...`。
- 支持表达式优先级：括号最高，乘除高于加减。
- 支持 `if`、`if-else`、`while` 的跳转标签代码。
- 增加简单语义检查：常量除以 0 会输出 `SemanticError`。

## 输出文件

- `tokens.txt`：Token 序列。
- `parse.txt`：文法产生式 + 当前真实含义。
- `parse_tree.txt`：缩进语法树。
- `tac.txt`：三地址代码。
- `symbols.txt`：标识符表。
- `constants.txt`：常量表。
- `errors.txt`：词法、语法、语义错误。
