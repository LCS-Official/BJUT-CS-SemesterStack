# 实验报告与 PPT 提纲

## 一、综合报告结构

1. 组内分工与贡献介绍
2. 系统功能概述
3. 系统总体结构
4. 词法分析子系统
   - 正规式描述
   - 正规文法
   - 状态图
   - 数据结构与算法
5. 语法分析子系统
   - 改写后的产生式集合
   - 递归下降分析函数
   - 语法错误处理
6. 三地址代码生成器
   - 语法制导定义
   - 属性设计：place、true、false、next
   - newtemp/newlabel/emit
7. 典型输入输出
8. 实验体会

## 二、PPT 建议页数

1. 标题页：小型编译前端系统设计与实现
2. 实验目标：三个实验合并为完整系统
3. 总体流程图：input -> tokens -> parse -> tac -> errors
4. 组内分工
5. Token 与接口统一
6. 词法分析设计
7. 语法分析设计
8. 三地址代码生成设计
9. GUI 和命令行演示
10. 测试结果：老师样例
11. 错误处理演示
12. 总结与体会

## 三、现场演示流程

1. 打开 GUI。
2. 填入老师样例。
3. 点击“编译并生成输出文件”。
4. 展示 tokens.txt：说明词法分析结果。
5. 展示 parse.txt：说明语法分析过程。
6. 展示 tac.txt：说明三地址代码。
7. 修改源程序，加入错误，例如缺少分号或非法字符 `@`。
8. 展示 errors.txt：说明错误定位和恢复。
