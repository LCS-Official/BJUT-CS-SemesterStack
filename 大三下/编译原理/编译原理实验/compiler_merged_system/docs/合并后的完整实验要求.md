# 合并后的完整实验要求

## 一、总体目标

把实验一、实验二、实验三合并成一个完整系统：

```text
源程序 input.txt
  -> 词法分析，生成 Token 序列 tokens.txt
  -> 语法分析，判断程序结构是否合法 parse.txt
  -> 语法制导生成三地址代码 tac.txt
  -> 错误处理 errors.txt
```

系统定位：一个“小型语言到三地址代码”的编译前端，不是完整 C 编译器。

## 二、统一开发方案

建议全组最终统一用 Python 面向对象实现，便于集成和 GUI 演示。原有 C/C++/Lex/Yacc 单独实验可以作为参考材料，但最终验收展示以本合并系统为主。

核心类：

- `Lexer`：词法分析器，只通过 `scan()` 返回下一个 Token。
- `Parser`：递归下降语法分析器，只通过 `Lexer.scan()` 取词。
- `CodeGenerator`：负责 `newtemp()`、`newlabel()`、`emit()`。
- `pipeline.compile_file()`：负责完整流程和四个输出文件。

## 三、Token 类型和属性

Token 结构：

```python
@dataclass(frozen=True)
class Token:
    type: TokenType
    lexeme: str
    attr: str
    line: int
    column: int
```

统一属性规则：

- `IDN`：属性是变量名。
- `INT10`：十进制值。
- `INT8`：转换成十进制后的值。
- `INT16`：转换成十进制后的值。
- `REAL10 / REAL16`：转换成十进制后的实数值。
- 关键字、运算符、分隔符：属性为 `_`。
- 错误 Token：属性为错误说明。

## 四、词法分析要求

必须识别：

- 标识符：字母开头，后接字母或数字。
- 关键字：`if then else while do`。
- 整数：`INT10`、`INT8`、`INT16`。
- 扩展实数：`REAL10`、`REAL16`。
- 运算符和分隔符：`+ - * / > < = ( ) ; { }`。
- 空白符跳过，但更新行号和列号。
- 非法字符写入 `errors.txt`。

输出文件：`output/tokens.txt`。

## 五、语法分析要求

采用递归下降法，统一文法：

```text
P  -> S ; P'
P' -> S ; P' | ε

S  -> id = E
S  -> if C then S
S  -> if C then S else S
S  -> while C do S
S  -> { P }

C  -> E > E
C  -> E < E
C  -> E = E

E  -> T E'
E' -> + T E' | - T E' | ε

T  -> F T'
T' -> * F T' | / F T' | ε

F  -> ( E )
F  -> id | int8 | int10 | int16 | real10 | real8 | real16
```

注意：`S` 本身不吃分号，分号由 `P -> S ;` 统一处理。

输出文件：`output/parse.txt`。

## 六、错误处理要求

错误格式：

```text
SyntaxError at line 行号, column 列号: expected XXX, got YYY
LexicalError at line 行号, column 列号: ...
```

基本恢复策略：遇到语法错误后跳到下一个 `;`、`}` 或 `EOF`，继续分析后续语句。

输出文件：`output/errors.txt`。

## 七、三地址代码生成要求

统一函数：

```python
generator.newtemp()   # t1, t2, ...
generator.newlabel()  # L0, L1, ...
generator.emit(code)
```

算术表达式：

```text
t1 := b * c
t2 := t1 + d
a := t2
```

条件跳转：

```text
if a > b goto L1
goto L2
```

while 示例：

```text
L0:
if a < b goto L1
goto L2
L1:
t1 := a + 1
a := t1
goto L0
L2:
```

输出文件：`output/tac.txt`。

## 八、必须测试的输入

1. 词法测试：`0 92+data>0x3f 00 while`
2. 表达式测试：`a = b * c + d;`
3. if 测试：`if a > b then x = 1;`
4. while 测试：`while a < b do a = a + 1;`
5. 指导书综合样例：

```text
while (a3+15)>0xa do
if x2 = 07 then
while y<z do
y = x * y / z;
c=b*c+d;
```

6. 错误恢复测试：缺少分号、括号不匹配、非法字符等。
