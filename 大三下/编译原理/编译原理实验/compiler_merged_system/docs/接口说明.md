# 接口说明

## Lexer

```python
lexer = Lexer("input.txt")
token = lexer.scan()
```

语法分析器只能通过 `scan()` 获取 Token，不直接读取字符流。

## Parser

```python
parser = Parser(lexer, codegen)
ok = parser.parseProgram()
```

统一函数名：

- `parseProgram()` / `parseP()`
- `parseStmt()` / `parseS()`
- `parseCond()` / `parseC()`
- `parseExpr()` / `parseE()`
- `parseTerm()` / `parseT()`
- `parseFactor()` / `parseF()`

## CodeGenerator

```python
codegen = CodeGenerator()
t = codegen.newtemp()
L = codegen.newlabel()
codegen.emit("t1 := a + b")
```
