# 标注规范

标注目标是把模型的自然语言回复转成可挖掘的结构化行为特征。可以采用“强模型自动预标注 + 人工复核”的流程：先用 `src/auto_annotate.py` 生成初始标签，再由组员重点复核低置信度、错误样本和抽样样本。

## 1. 基础字段

- `run_id`：一次模型调用的唯一编号。
- `prompt_id`：对应 Prompt 矩阵中的编号。
- `scenario_id`：空间场景编号。
- `geometry_type`：空间几何类型，例如规则 L 形、照片式不规则平台、管井缺口、梯形平台。
- `obstacle_type`：障碍物类型，例如管道、消防栓箱、栏杆、管井。
- `level`：`L1` / `L2` / `L3`。
- `perturbation_type`：扰动类型。
- `motion_constraint`：运动约束。当前老师题目统一为 `straight_segments_stop_turn`，表示只能直线运动，转弯需停车调向。
- `image_path`：发送给模型的图片。当前只能是 `楼梯转角实地图.jpg`，不能是带红框答案提示的 `题目示意图.png`。
- `model_key`：模型标识。
- `temperature`：采样温度。

## 2. 判断字段

### final_judgment

模型最终认为轮椅能否通过。

- `pass`：明确认为可以通过。
- `blocked`：明确认为不能通过。
- `uncertain`：认为无法判断、需要更多信息、只能给条件判断。
- `no_answer`：未回答问题或拒答。

标注原则：

- 以最终结论为准。
- 如果过程说能过、结尾说不能过，标最终结论，并在 `failure_mode` 中标 `self_contradiction`。
- 如果模型给出“取决于……”且没有明确倾向，标 `uncertain`。

### reference_judgment

人工基准判断。

- `pass`
- `blocked`
- `borderline`
- `unknown`

说明：本项目不是几何算法项目，但需要一个人工基准来计算准确率。可以由组员基于简化模型、常识判断或外部几何计算器给出。

### is_correct

模型判断是否与人工基准一致。

- `1`：一致。
- `0`：不一致。
- 留空：人工基准为 `borderline` 或 `unknown`。

## 3. 推理过程字段

### reasoning_step_count

粗略统计模型显式推理步骤数量。

- 如果模型用编号列表，按编号数。
- 如果没有编号，按主要推理句群估计。
- 只输出结论时填 `0` 或 `1`，全组保持一致。

### uses_formula

是否出现公式、代数表达、明确计算。

- `1`：出现公式或数值计算。
- `0`：没有。

### uses_coordinate_system

是否显式建立坐标系、平面几何模型、包络线、可行域等。

- `1`：有。
- `0`：没有。

### spatial_modeling_depth

空间建模深度，0 到 3。

- `0`：纯直觉判断，没有几何关系。
- `1`：提到宽度、长度、转弯空间等空间因素，但没有结构化推理。
- `2`：使用尺寸比较、转弯半径、安全余量等半形式化推理。
- `3`：建立坐标系、扫掠包络、二维约束或明确几何模型。

## 4. 错误类型字段

### failure_mode

如果模型明显错误或逻辑不稳定，选择一个主错误类型。

- `no_error`：未发现明显错误。
- `concept_confusion`：混淆宽度、长度、转弯半径、旋转包络等概念。
- `motion_constraint_ignorance`：忽略“只能直线运动、转弯需停车调向”的题目约束，按连续弧线转弯或普通转弯半径直接判断。
- `calculation_error`：计算或公式使用错误。
- `unsupported_assumption`：擅自补充关键条件。
- `boundary_neglect`：忽略临界边界、安全余量或不确定性。
- `obstacle_ignorance`：忽略管道、消防栓箱、管井、栏杆等固定障碍物。
- `false_obstacle_removal`：把题目明确说不可移动的障碍物当作可以移走或临时绕开。
- `irrelevant_noise_distraction`：被无关信息带偏。
- `self_contradiction`：过程和结论互相矛盾。
- `over_refusal`：过度拒绝回答，本可给出条件性分析却不分析。
- `other`：其他，需在备注中说明。

### error_note

一句话记录证据，例如：

- “把轮椅宽度 70cm 当成转弯直径。”
- “前文说平台不足，结论却说可以顺利通过。”
- “加入扶手颜色后，结论从 blocked 变为 pass。”

## 5. 一致性标注建议

对同一 `scenario_id` 和同一模型：

- 先标无扰动基线。
- 再标干扰版本。
- 如果只因无关信息导致 `final_judgment` 改变，`judgment_flip` 填 `1`。
- 如果 L1、L2、L3 对同一物理场景给出不同判断，也记录为层级不一致。

## 6. 自动预标注后的人工复核

自动预标注会额外生成：

- `auto_label_confidence`：自动标注模型对标签的置信度。
- `auto_label_raw`：自动标注模型输出的原始 JSON，便于追溯。
- `review_required`：是否建议人工复核。

人工复核优先级：

- `review_required=1`。
- `failure_mode` 不是 `no_error`。
- `is_correct=0`。
- `final_judgment` 与回复最后一行明显不一致。
- 每个模型、每个场景随机抽查 10% 到 20%。

复核时可以直接修改自动生成的标签；不要修改原始 `response_text`。
